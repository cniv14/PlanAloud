# 序言 Android 1.5.4 更新日志

- 周预览恢复细格子线，保持统一透明底和全天事项的连续浅色背景，不使用棋盘式底色。
- 顶部星期行固定在周表上方，只随日期横向移动；左侧时段列固定在周表左侧，只随时段纵向移动。表头与表体保持对齐，表体继续支持斜向同时拖动。
- 桌面小组件勾选完成改由后台广播处理，不启动界面、不弹出应用；更新事项后刷新小组件与提醒。点击事项内容仍可打开详情。
- 首页与桌面小组件的每日进度加入事件彩色时间段。事件按开始／结束时刻定位，跨午夜事件按当天范围裁切，重叠时段分行显示（最多六行）。首页点按时间线可查看颜色对应的事件和时段。
- 沿用 1.5.2／1.5.3 正式签名。

本轮按要求仅向 GitHub 提交这份更新日志，源码改动与构建包保留在本地，不创建新版 Release、不上传 APK、模块或签名附件。

验证：正式包构建、Android Lint、27 项 JUnit / Robolectric 回归，包含表头固定与滚动对齐、跨午夜与重叠事件、组件勾选不启动 Activity。尚未进行实体手机和各厂商桌面启动器复测。
