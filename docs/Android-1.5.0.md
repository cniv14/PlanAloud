# 序言 Android 1.5.0

下载 `PlanAloud-android.apk`，可覆盖安装同签名的 1.4.2。也可在「设置 → 更新」检查更新。

- 悬浮助手支持在半透明小窗内聊天和预览截屏。截屏经 Android 授权，点发送后才交给 AI。点「折叠」收为侧边竖线，点「关闭」会请求确认。支持从小窗打开序言，遮罩默认使用应用主题色。
- 底栏保留半透明渐变和正方形选中底。底栏与悬浮助手都以图标为触控中心。
- 从「更多功能」进入页面后，返回可恢复搜索与滚动位置。AI 聊天中输入 `/` 可查看指令，使用 `/calendar`、`/wallpaper` 等直接打开页面。
- 月历缩小周行间距，超长节日文字横向滚动。挂件支持调节玻璃遮罩。默认背景使用主题渐变，壁纸可在导入时裁切。
- 回收站默认保留 30 天，支持手动彻底删除。删除标记沿用现有同步协议。修复了打开数据库时的 `SQLITE_OK` 报错。

Android APK 约 5.2 MB。Windows 与服务端包沿用上一版。APK 和更新清单经过签名校验。本次离线打包跳过 Release lint，真机交互请以实机为准。
