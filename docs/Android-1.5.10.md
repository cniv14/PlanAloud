# Android 1.5.10

基于 1.5.9 正式发布对应的源码分支修复。

- Android 12 及以上的近期日程组件卡片与外框采用原生圆角裁切，Android 8–11 保留位图圆角回退，避免低分辨率位图圆角拉伸后边缘模糊。静态背景与动画帧使用相同裁切，动画帧由 96×36 提升至 300×110。
- “今天与明天”组件恢复独立深色底、固定文字颜色和事件侧边色条，不再读取应用或单个事项的卡片图片、纹理、优先级装饰与动画。
- 移除课表专用页面、课程类型选择、截图草稿、学期／节次／教学周配置，以及对应的 AI 工具和命令。安排统一使用日程的日期、时间、地点和重复规则。双栏首页保留，名称改为“双日”。
- 已保存或同步过来的旧课程继续参与日程显示、提醒、完成和同步；不批量重写旧记录的 ID 或 revision。编辑旧课程时按普通日程处理。
- CSV 与 HTML 导入改用普通日程字段，提供新日程模板；保留 ICS 导入。AI 图片提取使用收集箱候选与日程确认流程。

版本代码 160，版本名称 1.5.10。

签名：构建环境尚未恢复原正式签名。未签名 Release 构建只能用于后续签名，不可直接安装；Debug 包仅用于开发验证，不能覆盖现有正式版。正式发布和自动更新清单须在恢复原证书后生成。

验证：Debug 和未签名 Release 构建、Android Lint（0 错误）、仪器测试源码编译、7 项针对性回归均通过。回归覆盖 Android 12 的原生裁切、Android 9 的位图圆角像素、双日组件固定样式、日期式 CSV 去重、旧课程与提醒保留、每周重复及旧命令移除。未进行实体手机复测。

正式签名的加密备份仍保留在 `builds/android-1.5.2` 分支的 `PlanAloud-signing-1.5.2.enc.json`，恢复需要原先单独保存的解密凭据。
