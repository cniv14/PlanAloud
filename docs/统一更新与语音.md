# 统一更新与语音模块

从Android 1.3.2起，设置→统一更新负责主包与功能模块的分发来源。GitHub目录默认`https://github.com/cniv14/PlanAloud/releases/latest/download`，也可填写自己的附件目录。服务端使用当前日栖服务器与现有登录令牌；不会把令牌发给GitHub，不跨来源回退。

## 架构

助手、Markdown、黄历、语音转换为Android library，随本体提供可用基础版本。共享Material、Markwon、lunar等依赖与资源，避免多个独立APK重复存储。1.5.2 移除本地语音引擎、模型及下载接口，保留语音模块入口和识别结果回填协议。插件代码包只含自己的DEX；运行时按签名验证后加载，固定的非导出Activity由宿主组件工厂实例化，保留Android生命周期和原生UI。Android 9+支持此路径，Android 8回退内置功能。

签名外层与原有更新一致，模块payload字段：`schema=1,platform=android-module,api=1,id=assistant|markdown|almanac|voice,version,version_code,min_app_code,max_app_code,sha256,dex(base64)`。当前模块修订号132001对应1.3.2-r1，基础版本132。必须单调递增并匹配基础版本范围；资源ID、公共依赖和原生ABI由基础版本提供，不可通过代码包任意增加权限或资源。升级基础包后不兼容的旧补丁会回退内置实现。当前/上一份签名包和下载高水位在设备本地保存，不进入用户同步数据。

更新设置常驻基础包；模块异常恢复内置版本。回退不会被同修订自动覆盖，后续发布需增加模块修订号。更新不强行关闭当前编辑器，退出重开对应功能后生效。自动检查由系统每12小时调度，无常驻下载轮询；不会静默安装主包APK。

## 服务端接口

`GET /v1/updates/<name>`，Bearer鉴权。允许文件名为`android-update.json`、`DayFlow-android.apk`、`runtime-update.json`、`assistant-module.json`、`markdown-module.json`、`almanac-module.json`、`voice-module.json`、`voice-engine.json`、`voice-engine-arm64.zip`、`voice-engine-armv7.zip`、`voice-model.json`、`voice-model.bin`。所有文件放在`DAYFLOW_UPDATES_DIR`目录；目录已在Docker以只读方式挂载，不需为发布文件重启服务。

旧`/v1/runtime-update`仍兼容；旧`/updates/`白名单保留但现在也必须登录。所有分发路径共享按账号持久化的请求额度，默认`DAYFLOW_RUNTIME_REQUESTS=10`、`DAYFLOW_RUNTIME_WINDOW_SECONDS=3600`，多设备共享；401需登录，404未部署，429附Retry-After。一个完整检查通常请求四个模块及主包清单，启用主界面覆盖时再增加一个请求。管理员可提高额度，Android不会自动转GitHub规避限流。

## 语音

扩展与存储 → 语音识别配置，或助手麦克风进入同一模块。默认 DeepSeek 官方 ASR，也可选择系统服务或百炼 Qwen-ASR。

使用官方 DeepSeek 地址保存 AI 配置时，语音同步使用该密钥，无需重复配置。接口为 `POST https://api.deepseek.com/v1/tools/asr`，multipart `file` 上传 16 位 PCM WAV。非官方网关的密钥不会发送给 DeepSeek；可以单独设置 DeepSeek 语音密钥。见 [官方 ASR 文档](https://api-docs.deepseek.com/zh-cn/api/asr)。

录音为 16kHz 单声道，单次最多 120 秒，离开页面立即停止；临时 WAV 在识别结束后删除，不进入笔记或同步。识别文字先填入输入框，由用户编辑后发送。

1.5.2 不再编译、加载或下载本地识别引擎和模型。升级会移除旧模型和引擎缓存，不删除其他文件。语音 Activity、`settings_only` 参数和 `voice_text` 返回字段保持兼容，签名功能模块更新接口保留。

## 打包

Android 使用 JDK17、SDK36 和 Gradle9.6.1，不再需要语音 NDK、CMake 或模型源码。构建 `:app:assembleRelease :app:assembleDebug :app:exportModuleClasspath`。

`tools/package_feature_modules.py` 从四个 AAR 生成签名代码包。`tools/package_android_release.py --embedded-modules --skip-ocr --refresh-server` 整理主包及模块附件，不再要求原生语音包。正式签名私钥只存于维护者的构建环境，不能提交到仓库或发布附件。
