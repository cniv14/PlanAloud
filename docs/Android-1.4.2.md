# 序言 · Plan Aloud 1.4.2

- 桌面显示名改为「序言」，英文系统显示 Plan Aloud。Android 新包名为 `app.planaloud`，会与旧版分开安装。先在旧版导出同步文件，再在序言导入，或重新登录原服务端同步。应用设置和本机凭据需重新配置。
- 已连接序言服务端时，默认经服务端获取天气和搜索城市。服务端不可用时自动尝试开放来源。可在「位置与天气」关闭服务端优先。
- 桌面小组件支持单列和双列。单列展开标题、时间、截止倒计时、地点和备注。窄尺寸使用单列。
- 返回日历时保留选中日期和滑动位置。收集箱新增「待批准」和「回收站」。
- 用户直接交代的 AI 新建事项立即保存。需要核验的资料候选和高影响操作可在收集箱处理。助手顶部可逐步撤销最近的助手操作，回收站也可打开最近操作记录。

部署新版服务端后，客户端可使用登录态访问 `GET /v1/weather`。预报传 `kind=forecast&lat=…&lon=…`，搜索传 `kind=cities&q=…`。服务端只请求固定天气来源，按位置或城市词缓存，返回来源和原始天气数据。旧服务端仍可同步，天气会自动走开放来源。

旧 Docker 部署迁移时，先备份并停止旧容器，设置 `PLANALOUD_DATA_VOLUME` 为现有数据卷名，再启动新服务。新服务会继续读取数据卷中的旧数据库。文件备份仍兼容旧版 `.dayflow` 格式。

Windows 安装包包含 PlanAloud.Widget.exe 与 PlanAloud.Updater.exe。新程序会读取现有的旧版 Windows 数据目录。
