# 序言 Android 1.5.5 更新日志

- 主页进度条从事件色段引出同色斜线，右侧仅标注事件名称。长名称省略显示，点击可查看完整内容；名称较多时单独上下滚动名称列，保持主页紧凑。文字在浅色／深色主题下保持可读。
- 周预览改为按实际时间排列，默认 08:00–22:00，超出自动扩展并在左侧标注。事件高度对应持续时间，重叠安排并排显示；保留格子线、固定日期／时间轴和自由双向滚动。
- 全天事项作为当天的连续背景，通过侧栏查看名称；只有截止日期的待办放在底部固定细条中，点击查看完整内容，不虚构开始时间。
- PNG 导出同步使用真实时间网格，并附完整事项清单，短时和重叠安排的名称不会因格子太小而丢失。
- 设置 → 外观 → 界面与字体大小，新增独立界面缩放（70–130%）和字体大小（80–160%），支持恢复默认。仅调整应用，保留系统设置；应用时保留当前设置页。AI、笔记、语音、黄历在重新打开后使用相同缩放。
- 压缩首页日期区，将新建待办／周预览改为日期旁的图标；底部导航、AI 和悬浮窗合并为单排图标，保留长按提示及无障碍名称，减少上下栏占用。
- 指引和周表帮助同步更新。

正式版沿用 1.5.2 起的证书，可覆盖升级；Debug 独立发布，不能覆盖正式安装。

验证：正式／Debug 构建、Android Lint、41 项自动回归（真实时间布局、跨午夜、重叠分栏、截止待办、缩放保存与界面恢复、单排导航、名称滚动及现有功能），并使用原生 Canvas 生成首页和周表测试预览。尚未进行实体手机复测。
