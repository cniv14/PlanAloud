# 日栖 1.3.3 指令与壁纸规则

首页只保留新建、周预览和指令。长按「问日栖」也能打开指令台。输入 `open wallpaper`，或搜索中文「壁纸」，可以直接打开对应页面。`help` 查命令和参数，`screen.list` 查所有页面。

## 待办计划

- `due_date`：截止日期，例如 `2026-11-20`。
- `due_time`：截止时刻，例如 `17:30`；必须与日期一起使用，可单独留空。
- `estimate_minutes`：预计用时，单位分钟。它不等同于日程时段长度，也不会自动填写开始或结束时间。
- `priority`：`high` 高重要（红）、`normal` 普通（琥珀）、`low` 低重要（蓝）；不填写时使用主题原色。深色主题使用对应深色底。

这些字段随同事项同步和备份。周预览中，截止行独立于上下午等时段；一个已经排了时间的任务，也能在其截止日期一栏再次提示。无日期的任务留在「待安排」。

## 终端与 AI

1. 先覆盖安装 1.3.3 本体（包含新的指令入口和小组件组件）。在「指令台」打开「允许已授权电脑通过 ADB 运行命令」。手机仍需通过系统授权连接该电脑；日栖不启动 HTTP 服务。
2. 电脑安装 Android platform-tools，使 `adb` 可用，或传 `--adb` 指定其路径。多设备用 `--serial`，非默认 Android 用户可用 `--user`。
3. 使用仓库内的 `tools/dayflow.py`（预览目录提供同一脚本，可直接 `python dayflow.py`）。查询和数据操作不要求打开 Android 界面。

```powershell
python tools/dayflow.py help
python tools/dayflow.py agenda.week
python tools/dayflow.py record.create --args-file task.json
python tools/dayflow.py settings.set --args-file widget.json
python tools/dayflow.py assistant.ask --args-file prompt.json
python tools/dayflow.py backup.export --output my.dayflow
python tools/dayflow.py backup.import --input my.dayflow
python tools/dayflow.py notes.import '{"title":"读书笔记"}' --input notes.md
python tools/dayflow.py calendar.import '{"format":"ics"}' --input class.ics
python tools/dayflow.py screen.open '{"page":"widget"}'
```

`task.json` 示例：

```json
{"kind":"task","title":"交作业","due_date":"2026-11-20","due_time":"17:30","estimate_minutes":45,"priority":"high"}
```

`widget.json` 示例：`{"key":"widget_layout","value":"grid"}`。`prompt.json` 示例：`{"text":"列出明天的截止事项"}`。修改和删除使用 `record.get` 或 `record.search` 得到的 ID 和 revision；可选字段传 `null` 即清除。对长笔记使用 `record.export` 或 `notes.export` 取完整内容，搜索结果只包含摘要。

`sync.login` 与 `sync.connect-taskflow` 的凭据请用 `--args-file` 或 `--args-file -` 从标准输入读入，避免密码进入命令历史。文件传输使用应用的私有暂存区，脚本结束后清理。AI 不获取同步口令或任意文件路径。系统权限、安装确认等操作用 `screen.open` 打开对应界面，再按 Android 要求确认。

AI 使用 `dayflow_command` 调用同一注册表。删除、候选加入日程、课表导入等默认在对话内显示批准卡；不会因为读到截图或通知中的文字就自动写入正式日程。可在 AI 设置中选择「允许 AI 自动批准」，然后在对话明确要求 AI 批准。终端 AI 若返回 `approval_token`，在同一会话中执行 `assistant.approve`，参数为 `{"token":"…","approved":true}`。令牌绑定会话并限时，批准时会再次检查记录或草稿版本；新会话不会沿用旧授权。

## 壁纸规则

在「外观 → 壁纸轮播与规则」导入图片并编辑规则。应用将配置原子写入本机 `wallpapers/rules.json`，也可用页面上的 JSON 导入/导出，或调用 `wallpaper.get`／`wallpaper.set`。在另一台设备导入规则前，需要导入图片，并将配置中的 ID 改成该设备的 ID。配置文件不包含图片。

```json
{
  "schema": 1,
  "rotate_minutes": 15,
  "images": [
    {"id": "替换为实际图片 UUID", "name": "星空.jpg"}
  ],
  "rules": [
    {"image": "替换为同一个 UUID", "priority": 20, "when": "time[night] && (weather[sunny] || event[none])"}
  ]
}
```

支持 `always`；`time[night]`、`time[weekday]` 或 `time[22:00-06:00]`；`weather[sunny]`、`weather[rain]` 等天气缓存条件；`event[active]`、`event[none]`、`event[course]` 或 `event[title:会议]`。`&&` 优先于 `||`，可以用括号调整。数字越大优先级越高；同级多张图可循环。无匹配时，从图库轮播或使用指定默认图。应用在前台时按低频定时器重新计算，切换用渐变过渡；天气使用已保存的当前或预报数据，不为换图每次联网。

桌面小组件在「小组件样式」中选择单列或两列矩阵，两种都可上下滚动。组件过窄时自动用单列。玻璃效果由渐变、高光和图片遮罩组成；跟随应用壁纸时，桌面更新时机还受启动器调度影响。支持跟随深浅主题以及重要程度底色。

ADB 参数及文件通道可参阅 [Android 开源实现](https://android.googlesource.com/platform/frameworks/base/+/refs/heads/main/cmds/content/src/com/android/commands/content/Content.java)。
