# 日栖 Android 1.4.0

使用 `DayFlow-android.apk` 安装。正式签名的旧版日栖可直接覆盖安装。

- 待办显示距截止或逾期的时间。24 小时内截止或已逾期显示红色，重要显示紫色，紧急显示黄色，普通显示蓝色，低优先和时间宽裕的未分级待办显示绿色。
- 长按待办、日程或笔记可打开操作菜单。日程编辑表格和桌面小组件也提供删除入口。删除可撤销，重复日程的单次删除只影响本次。
- 笔记点按进入 Markdown 预览，编辑默认打开内嵌 Markdown 编辑器。收集箱通知点按打开来源应用，长按可查看已收集的内容。
- 月历在日期正下方显示农历，另行显示节日和调休。长按日期可添加或清除本机标注。
- 在「位置与天气」填入和风天气控制台提供的 API Host 和 API Key，即可搜索城市、获取实时天气及最多 10 天的日预报。

安装包使用原发布证书。可用 `SHA256SUMS.txt` 校验下载文件。公式渲染器的对应上游源码随包提供。
